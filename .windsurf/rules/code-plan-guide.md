1. 遵守docs/下的md文档的开发规范，尤其是跨平台
2. 你需要根据docs/目录下的原型进行开发
3. 精细化开发，能复用或者可能会复用的组件要添加到components下，比如说布局组件，侧边栏组件，卡片组件等等
4. 你所写的任何样式都要符合响应式规范，样式css代码，放到styles下统一维护，尽量与vue文件分离
5. 遇到你不熟悉或者不知道的库或者API使用方法，请你使用Context7工具去查看最新文档
6. 原型html只供参考
 - 不要采用其中cdn的css或者字体之类的使用方法
 - 其中可能会有不完善或者不够准确的地方，请你自行修正
7. 开发时，你进行的每一步都要说明你的目的（但你无需停止向我确认，直接开发即可，我想看到的是你开发过程中的透明度）
8. 不要重复造轮子，根据package.json中的依赖去使用现成的组件/库，没有则使用pnpm添加适合的依赖
